# Super Hero Catch

A simple touch game for kids, made for Android phones (runs in Chrome, no install needed).

- Slide your finger to fly the caped hero left and right.
- Catch 🍌 (1), ⚽ (2) and 🐦 (3). A ⭐ gives 5 seconds of **Star Power**: a golden glow,
  a rainbow trail, a magnet that pulls treats in, and a shield against storms.
- Dodge ⛈️ storm clouds, which cost a heart.
- Every 25 points: level up, confetti, and the sky changes (day → sunny → sunset → dusk → night).
- A voice cheers the hero by name, in English or Egyptian Arabic. Arabic is used when the
  name is typed in Arabic letters. You can turn the voice off on the start screen.

On the start screen, type the hero's name and tap **📷 Photo** to choose a face from the
phone's gallery. The name, photo and best score are saved on that device only.

To put it on the home screen: open `index.html` in Chrome on Android, then tap
⋮ → **Add to Home screen**. It opens fullscreen like an app.

This public copy has no photo built in. The game can show a full-body cut-out if one is
embedded in `HERO_SPRITE` (a transparent PNG/WebP data URL). That was left empty here on purpose.
