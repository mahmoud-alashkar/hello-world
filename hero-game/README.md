# Super Hero Catch

A simple touch game for kids, made for Android phones (runs in Chrome, no install needed).

- Slide your finger to fly the hero left and right.
- Catch 🍌 (1), ⚽ (2), 🐦 (3) and ⭐ (5). Dodge ⛈️ storm clouds, which cost a heart.
- Every 25 points the game levels up and speeds up a little.

On the start screen, type the hero's name and tap **📷 Change hero photo** to choose a face
from the phone's gallery. The name, photo and best score are saved on that device only.

To put it on the home screen: open `index.html` in Chrome on Android, then tap
⋮ → **Add to Home screen**. It opens fullscreen like an app.

This public copy has no photo built in. It shows a cartoon face until you choose one.
